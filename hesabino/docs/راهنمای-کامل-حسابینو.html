راهنمای کامل حسابینو

نسخه ۱.۰.۰ · فقط اندروید ۸ به بالا · بدون اینترنت · فایل: Hesabino-v1.0.0.apk (حدود ۱۹ مگابایت)

حسابینو پول را به بانک وصل نمی‌کند. تراکنش را خودتان ثبت می‌کنید، یا از روی پیامک بانکی روی همین گوشی استخراج می‌شود. هیچ داده‌ای به سرور نمی‌رود.

۱) نصب روی گوشی

پیش‌نیاز

  • اندروید ۸.۰ یا جدیدتر
  • حدود ۳۰ مگابایت فضای خالی
  • این اپ از گوگل‌پلی نیست؛ باید نصب از «منبع ناشناس» را برای همان برنامهٔ دانلود (کروم / فایل‌ها) روشن کنید

مراحل نصب (پیکسل / اندروید خام)

  1. فایل Hesabino-v1.0.0.apk را روی گوشی کپی کنید (دانلود، تلگرام، کابل، گوگل‌درایو…).
  2. با برنامه Files یا Downloads روی APK بزنید.
  3. اگر پیام «برای امنیت، نصب از این منبع مسدود شد» آمد:
    1. دکمه Settings / تنظیمات را بزنید
    2. گزینه Allow from this source را روشن کنید
    3. برگردید و دوباره Install را بزنید
  4. اگر Play Protect هشدار داد که برنامه ناشناخته است: Install anyway / نصب به‌هرحال را بزنید. این به‌خاطر این است که APK را خودمان امضا کرده‌ایم، نه گوگل‌پلی.
  5. بعد از نصب، Open / باز کردن.

مراحل نصب روی سامسونگ / شیائومی / هواوی

  1. تنظیمات → امنیت / حریم خصوصی → نصب برنامه ناشناس → برنامه My Files یا Chrome را اجازه بدهید.
  2. شیائومی: گاهی باید در Security → Install via USB / MIUI optimization دخالت نکنید؛ فقط «نصب از منابع ناشناس» کافی است.
  3. اگر نصب فوراً بسته شد: در فایل منیجر، APK را «نصب» کنید نه «باز کردن با مرورگر».
توجه: این نسخه Debug است (برای استفاده شخصی). آنتی‌ویروس گوشی یا Play Protect ممکن است یک‌بار بپرسد. برنامه به اینترنت نیاز ندارد؛ می‌توانید بعد از نصب، Data را برایش ببندید.

۲) اولین ورود — چه می‌بینید

  1. آیکون سبز «حسابینو» را باز کنید.
  2. چهار تب پایین: خانه · تراکنش‌ها · خودکار · تنظیمات
  3. خودکار ساخته می‌شود:
    • حساب‌ها: نقدی، کارت ملت
    • دسته‌ها: خوراک، حمل‌ونقل، مسکن، قبوض، سلامت، پوشاک، سرگرمی، حقوق، …
  4. واحد پول پیش‌فرض: تومان با ارقام فارسی.

۳) ثبت دستی تراکنش (مسیر اصلی — ۲ حرکت)

  1. در خانه یا تراکنش‌ها دکمه سبز + را بزنید.
  2. صفحه‌کلید عددی باز است. مبلغ را به تومان بنویسید؛ مثلاً 120000.
  3. نوع پیش‌فرض «هزینه» است. دسته و حساب از آخرین انتخاب پر می‌شوند.
  4. ذخیره را بزنید.
نکته سرعت: اگر فقط مبلغ را عوض کنید و ذخیره بزنید، همان ۲ تعامل است. عنوان اگر خالی باشد از نام دسته پر می‌شود.

۴) فعال‌سازی پیامک بانکی (مهم‌ترین بخش)

بدون این مرحله، SMS به‌صورت خودکار خوانده نمی‌شود.

  1. تب تنظیمات → بخش پیامک بانکی.
  2. متن توضیح را بخوانید: پردازش فقط روی گوشی است.
  3. دکمه فعال‌سازی و اسکن پیامک‌های قبلی را بزنید.
  4. اندروید پنجره اجازه می‌آورد:
    • SMS / پیامک‌ها → Allow / اجازه
    • در اندروید ۱۳+: اگر Notifications هم پرسید، اختیاری است
  5. اگر اجازه را رد کنید، ثبت دستی همچنان کار می‌کند؛ فقط اتوماسیون SMS خاموش است.
  6. بعد از اجازه، اسکن inbox شروع می‌شود (تا حدود ۴۰۰ پیام اخیر). پیامک‌های بانکی به‌صورت پیش‌نویس در تب خودکار ظاهر می‌شوند.
اگر اجازه دیده نشد: تنظیمات اندروید → برنامه‌ها → حسابینو → مجوزها → پیامک → اجازه دادن.
بعضی گوشی‌های چینی (ColorOS / MIUI) SMS را در «مجوزهای خاص / Other permissions» مخفی می‌کنند.
ذخیره متن خام پیامک در تنظیمات پیش‌فرض خاموش است. روشن نکنید مگر بخواهید پارسر را دیباگ کنید.

۵) سناریوی نمونه: تن ماهی ۱۲۰٬۰۰۰ تومان

هدف: هر بار SMS برداشت دقیقاً ۱٬۲۰۰٬۰۰۰ ریال (۱۲۰٬۰۰۰ تومان) از ملت آمد، تراکنش «تن ماهی» در دسته خوراک ثبت شود.

  1. یک‌بار تراکنش را دستی ثبت کنید (یا از پیش‌نویس SMS تأیید کنید): عنوان «تن ماهی»، مبلغ ۱۲۰۰۰۰، دسته خوراک.
  2. روی همان تراکنش بزنید → ساخت قانون از این تراکنش.
  3. در قانون‌ساز:
    • نوع: برداشت
    • مبلغ دقیق: ۱۲۰۰۰۰ (تومان)
    • فرستنده شامل: مثلاً BMJI یا عدد کوتاه بانک ملت (از خود SMS کپی کنید)
    • ۴ رقم آخر کارت اگر در پیامک هست
    • عنوان عمل: تن ماهی · دسته: خوراک
  4. اگر فقط مبلغ را شرط کنید، نوار زرد هشدار می‌دهد — حتماً فرستنده یا عبارت متن را هم بگذارید.
  5. آزمایش روی پیام‌های اخیر را بزنید تا ببینید کدام SMSها match می‌شوند.
  6. سوییچ «ثبت قطعی خودکار»:
    • خاموش (پیشنهادی اول): هر تطبیق می‌رود پیش‌نویس؛ یک تپ تأیید
    • روشن: بدون پرسیدن، تراکنش قطعی ثبت می‌شود
  7. ذخیره قانون.
از این به بعد SMS جدید ملت با همان مبلغ → تب خودکار (یا مستقیم لیست تراکنش‌ها اگر auto-approve روشن باشد).

۶) پیش‌نویس‌ها (Drafts)

  1. تب خودکار → پیش‌نویس‌ها.
  2. برای هر مورد: تأیید (یک تپ) · ویرایش / قانون · رد.
  3. تأییدشده‌ها در تراکنش‌ها با منبع SMS دیده می‌شوند.
  4. اسکن دوباره inbox همان پیامک را تکرار نمی‌کند (اثرانگشت پایدار).

۸) مجوزهایی که اندروید نشان می‌دهد

پیامک (SMS)خواندن و دریافت پیامک بانکی — اجباری برای اتوماسیون
اعلاناختیاری
بیومتریکفقط اگر قفل اثرانگشت را روشن کنید

اندروید ممکن است مجوزهای کتابخانه‌ای مثل «وضعیت شبکه» یا «بعد از روشن شدن دستگاه» را هم لیست کند (از WorkManager). حسابینو سرور ندارد و حساب ابری نمی‌سازد.

۹) عیب‌یابی

SMS نمی‌آید داخل اپ
  • مجوز پیامک را در تنظیمات سیستم چک کنید
  • پیامک باید در inbox سیم‌کارت همین گوشی باشد (نه فقط در اپ بانک)
  • یک‌بار «اسکن پیامک‌های قبلی» را دوباره بزنید
  • اگر بانک از پیام‌رسان داخل‌اپ استفاده کند نه SMS، قابل خواندن نیست
مبلغ اشتباه است (۱۰ برابر / ۰.۱)
  • بانک‌ها معمولاً ریال می‌فرستند؛ حسابینو به تومان تبدیل می‌کند
  • اگر SMS خود بانک «تومان» نوشته، همان واحد خوانده می‌شود
  • از تنظیمات واحد نمایش را عوض کنید تا مطمئن شوید
تراکنش تکراری
  • اثرانگشت جلوی تکرار همان SMS در همان دقیقه را می‌گیرد
  • اگر دو خرید جدا با مبلغ یکسان در دو دقیقه متفاوت باشد، دو تراکنش درست است
اپ باز نمی‌شود / فوراً بسته می‌شود
  • اندروید را چک کنید (باید ۸+ باشد)
  • نصب را پاک کنید و دوباره APK را نصب کنید
  • روی شیائومی: در تنظیمات برنامه، Battery saver را Unrestricted کنید تا Receiver SMS کشته نشود
بعد از ری‌استارت گوشی، SMS جدید ثبت نمی‌شود
  • مجوز SMS را دوباره تأیید کنید
  • باتری → بدون محدودیت برای حسابینو
  • بعضی ROMها Broadcast SMS را برای اپ‌های سایدلود محدود می‌کنند؛ اسکن دستی از تنظیمات همیشه کار می‌کند

۱۰) حریم خصوصی — خلاصه برای اطمینان

  • بدون حساب کاربری، بدون کلود، بدون تبلیغ
  • دیتابیس فقط داخل حافظه برنامه است
  • بکاپ ابری اندروید برای این اپ خاموش است
  • پین به‌صورت hash+salt ذخیره می‌شود، نه خود پین
  • اگر گوشی را root کرده‌اید، امنیت فایل مثل هر اپ آفلاین دیگری است
