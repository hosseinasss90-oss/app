# حسابینو — تصمیم‌های محصول (قفل‌شده)

این سند فرض‌هایی است که به‌جای پرسش مسدودکننده گرفته شده‌اند.
اگر لازم شد قبل از انتشار تغییر کنند، فقط همین فایل را به‌روز کنید.

| موضوع | تصمیم | دلیل |
|---|---|---|
| نام | **حسابینو** (Hesabino) | کوتاه، فارسی، به‌یادماندنی |
| پکیج | `ir.hesabino.app` | دامنه ایرانی، بدون وابستگی به فروشگاه |
| واحد نمایش پیش‌فرض | **تومان** | زبان روزمره کاربر ایرانی |
| واحد ذخیره داخلی | **ریال (Long)** | SMS بانک‌ها غالباً ریال است؛ تبدیل بدون اعشار |
| نسبت | `1 تومان = 10 ریال` | استاندارد جاری (بدون فرض اصلاح ۴ صفر) |
| Min SDK | **26** (Android 8) | `java.time`، Notification Channel، پوشش >۹۵٪ |
| Target / Compile | **35** | آخرین API پایدار |
| بانک‌های فاز ۱ | ژنریک + ملت، ملی، صادرات، پاسارگاد، تجارت، سامان، پارسیان، آینده، رسالت، کشاورزی | پوشش فرستنده‌های پرتکرار |
| SMS بدون قانون | **Draft پیشنهادی** | هیچ پولی بی‌سروصدا ثبت نمی‌شود |
| چند قانون Match | بالاترین `priority`؛ تساوی → Draft انتخاب | قابل پیش‌بینی و امن |
| متن خام SMS | پیش‌فرض **خاموش** | حریم خصوصی |
| قفل اپ | PIN ۶ رقمی + بیومتریک اختیاری | داده مالی |
| حالت خصوصی | مخفی کردن ارقام با `••••` | استفاده در جمع |
| زبان/جهت | فقط فارسی، RTL اجباری | محصول ایران |
| تقویم | نمایش و فیلتر **شمسی**؛ ذخیره **ISO-8601 / epoch** | دقت + UX محلی |
| ثبت دستی ۲ تپ | FAB → مبلغ (فوکوس) → ذخیره | دسته/حساب از آخرین انتخاب |

## چیزهایی که عمداً در v1 نیستند

- همگام‌سازی ابری / اکانت کاربری
- اتصال مستقیم به بانک / Open Banking
- بودجه و اهداف پس‌انداز (فاز ۲)
- چندارزی (فقط ریال/تومان)
- ویجت صفحه اصلی (فاز ۲)
- اشتراک‌گذاری گزارش در شبکه اجتماعی
