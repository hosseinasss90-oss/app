هیچ گرادیان پرزرق‌وبرقی. سطح‌ها با elevation خیلی کم (1–2dp) و stroke 1px.

### تایپوگرافی

فونت: **Vazirmatn** (وزن 400 / 500 / 700)

| نقش | Size / Line / Weight | نمونه |
|---|---|---|
| Display | 34 / 40 / 700 | مبلغ خالص ماه |
| Title L | 22 / 28 / 700 | عنوان صفحه |
| Title M | 18 / 24 / 600 | نام دسته، عنوان کارت |
| Body L | 16 / 24 / 400 | متن فرم |
| Body S | 14 / 20 / 400 | یادداشت، متادیتا |
| Label | 12 / 16 / 500 | chip، caption |
| Numbers | tabular lining، وزن +100 نسبت به متن کنارش | ۱۲٬۰۰۰ |

اعداد همیشه با جداکنندهٔ هزارگان `٬` (U+066C) و در صورت تنظیم کاربر با ارقام فارسی.

### Spacing / Shape

```
space: 4 / 8 / 12 / 16 / 24 / 32
radius: 12 (chip) · 16 (کارت) · 28 (FAB / دکمه بزرگ)
touch: حداقل 48dp
padding صفحه: 16 افقی
```

### حرکت

- Duration: 200ms استاندارد، 320ms شیت‌ها
- Easing: emphasized decelerate
- ثبت موفق: Snackbar پایین + haptic سبک
- تأیید Draft: ردیف با fade به‌علاوهٔ تیک سبز

### 3.7 Settings

گروه‌ها با `ListItem` استاندارد:

1. نمایش — واحد (تومان/ریال)، ارقام فارسی/لاتین، حالت خصوصی
2. پول من — حساب‌ها، دسته‌ها
3. پیامک بانکی — وضعیت دسترسی، اسکن اولیه، ذخیره متن خام
4. داده — خروجی CSV، پشتیبان JSON، بازگردانی
5. امنیت — قفل، بیومتریک، تغییر PIN
6. درباره — نسخه، ارسال نمونه SMS برای پارسر جدید (متن را کپی می‌کند؛ ارسال شبکه ندارد)

## 4) جریان‌های کلیدی

### ثبت دستی (۲ تعامل)

```
Tap FAB  →  AddTx (مبلغ فوکوس، نوع=هزینه، دسته/حساب=آخرین)
Type amount + Tap ذخیره  →  popBack + Snackbar «ثبت شد · بازگردانی»
```

### SMS → تراکنش

```
SmsReceiver.onReceive
    → normalize + parse
    → fingerprint + dedup
    → persist BankEvent
    → RuleEngine.match
         ├ autoApprove + unique match → Transaction (SMS_RULE)
         ├ match ولی draft mode     → Draft PENDING
         ├ چند match هم‌اولویت      → Draft «انتخاب قانون»
         └ no match                 → Draft پیشنهادی (generic)
```

### ساخت قانون از نمونه

```
Tx Detail یا Draft  →  «ساخت قانون از این مورد»
    prefill: type, amount equals, sender, last4, title, category, account
    کاربر شرایط را کم/زیاد می‌کند
    Dry-run روی آخرین BankEventهای همان sender
    ذخیره → اختیاری: «روی پیش‌نویس‌های باز هم اعمال شود؟»
```

## 5) Empty / Error / Permission

| حالت | پیام | CTA |
|---|---|---|
| بدون تراکنش | هنوز چیزی ثبت نشده | ثبت تراکنش |
| بدون قانون | پیامک‌ها منتظر قانون‌اند | ساخت اولین قانون |
| SMS denied | برای ثبت خودکار، دسترسی پیامک لازم است | اجازه دادن + توضیح ۲ خطی |
| Unparsed SMS | پیامک بانک شناسایی نشد | ساخت قانون دستی / گزارش نمونه |
| Backup fail | فایل خوانده نشد | انتخاب مجدد |

توضیح دسترسی SMS (شفاف، بدون Play wording):
> «حسابینو پیامک‌های بانکی را فقط روی همین دستگاه می‌خواند تا تراکنش بسازد. متن پیامک‌ها به اینترنت ارسال نمی‌شود.»

## 6) Accessibility

- Contrast برند روی سطح ≥ 4.5:1
- FontScale تا 1.3 بدون شکستن ردیف‌ها (مبلغ wrap می‌شود)
- TalkBack: «هزینه، تن ماهی، صد و بیست هزار تومان، خوراک، امروز»
- حالت خصوصی: TalkBack هم ارقام را «مخفی» می‌خواند
- Target 48dp روی سوییچ قانون و دکمه‌های Draft
